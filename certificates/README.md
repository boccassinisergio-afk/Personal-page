# Cartella certificati

Carica qui i PDF dei certificati. Il nome del file deve corrispondere al link usato in `index.html`.

Per il certificato già collegato dalla home:

- `cs50p.pdf` -> certificato CS50P (Harvard)

Quando aggiungi una nuova certificazione:

1. Carica il PDF in questa cartella (es. `sql-certification.pdf`)
2. In `index.html`, nella sezione `#certifications`, aggiungi un link `<a class="pdf-link" href="certificates/nome-file.pdf" ...>`
