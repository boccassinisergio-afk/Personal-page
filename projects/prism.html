PRISM

2026· stabilestable

Pandas Report & Intelligent Summary Maker: una classe Python che genera automaticamente un report di analisi da un qualsiasi CSV. Pandas Report & Intelligent Summary Maker: a Python class that auto-generates an analysis report from any CSV.

python pandas oop

Il problemaThe problem

Ogni volta che si riceve un CSV nuovo, i primi passi (capire i tipi di colonna, individuare valori mancanti, calcolare statistiche di base) si ripetono quasi sempre uguali. PRISM automatizza questa prima esplorazione: basta passargli un file e restituisce un report strutturato. Every time you receive a new CSV, the first steps (understanding column types, spotting missing values, computing basic statistics) tend to repeat almost identically. PRISM automates this first exploration: just pass it a file and it returns a structured report.

Decisioni di designDesign decisions

  • Distinzione tra tipo logico e tipo pandas: una colonna numerica con pochi valori distinti (in base a un rapporto di cardinalità) viene trattata come categorica anche se pandas la vede come int64 Logical vs. pandas dtype distinction: a numeric column with few distinct values (based on a cardinality ratio) is treated as categorical even if pandas sees it as int64
  • Valutazione lazy con memoizzazione tramite sentinel None, per calcolare ogni riepilogo una sola volta anche se richiesto più volte Lazy evaluation with None-sentinel memoization, so each summary is computed only once even if requested multiple times
  • Costruttore alternativo @classmethod from_csv() per creare l'oggetto direttamente da un percorso file Alternative @classmethod from_csv() constructor to build the object directly from a file path
  • Metodi privati con prefisso underscore e costanti configurabili a livello di classe Private methods prefixed with an underscore and configurable class-level constants
  • Principio "fail-loud": errori nei dati vengono segnalati esplicitamente invece di essere nascosti "Fail-loud" principle: data errors are surfaced explicitly instead of being hidden
  • Pipeline di classificazione delle colonne basata su cinque tipi con priorità ordinata Column classification pipeline based on five priority-ordered types
