Un tool da riga di comando per tracciare concetti, argomenti e progressi di apprendimento. Costruito da zero, cresce insieme allo sviluppatore che lo ha creato. A command-line tool to track concepts, topics, and learning progress. Built from zero, growing alongside the developer who made it.

Cos'è SynapseWhat Synapse is

Synapse crea connessioni tra concetti: permette di registrare cosa si sta studiando, quanto bene lo si comprende e a che punto ci si trova, tutto dal terminale, tutto salvato localmente in un file CSV. L'idea alla base è che il tool cresca insieme alle competenze di chi lo usa. Synapse creates connections between concepts: it lets you log what you're studying, how well you understand it, and where you stand, all from the terminal, all saved locally in a CSV file. The idea behind it is that the tool grows alongside the skills of whoever uses it.

ArchitetturaArchitecture

Ogni record è modellato come un oggetto SynapseEntry invece che come un dizionario grezzo. La classe è l'unica definizione autorevole della struttura di una voce: @property espone id come sola lettura (sostenuto da _id, sempre un int), @classmethod from_dict() è un costruttore alternativo da riga CSV, to_dict() serializza di nuovo per csv.DictWriter, __str__ definisce la stampa. Il flusso dati è: riga CSV → dict → SynapseEntry → dict → riga CSV, con getattr/setattr per l'accesso dinamico ai campi nei cicli. Each record is modeled as a SynapseEntry object rather than a raw dictionary. The class is the single authoritative definition of an entry's structure: @property exposes id as read-only (backed by _id, always an int), @classmethod from_dict() is an alternative constructor from a CSV row, to_dict() serializes back for csv.DictWriter, __str__ defines the printed form. The data flow is: CSV row → dict → SynapseEntry → dict → CSV row, with getattr/setattr for dynamic field access inside loops.

La versione attuale (v2.1) è il risultato di un refactoring completo da un design procedurale a uno orientato agli oggetti, che ha sostituito la vecchia funzione standalone di stampa con il metodo __str__ e portato tutte le funzioni a operare su istanze reali invece che su dizionari. The current version (v2.1) is the result of a full refactor from a procedural design to an object-oriented one, replacing the old standalone print function with the __str__ method and moving every function to operate on real instances instead of dictionaries.

Parte di un sistema a due strumentiPart of a two-tool system

Synapse è la metà "verso l'interno" di un piccolo sistema di conoscenza personale: mappa concetti e progressi di apprendimento, mentre Pulsar traccia software costruito e contenuti pubblicati verso l'esterno. Costruito durante CS50P di Harvard, documentato nel repo pubblico cs50p-python. Synapse is the "inward-facing" half of a small personal knowledge system: it maps concepts and learning progress, while Pulsar tracks software built and content published outward.
