Traceweave

2026· stabile, in evoluzionestable, evolving

Un analizzatore di log HTTP in Python, costruito da zero per trasformare file di log grezzi in report leggibili. A Python HTTP log analyzer, built from scratch to turn raw log files into readable reports.

python pandas matplotlib argparse oop

Il problemaThe problem

I log di accesso HTTP in Common Log Format contengono informazioni preziose (chi visita cosa, quando, con quale esito) ma sono scomodi da leggere riga per riga. Traceweave prende un file di log qualsiasi in questo formato e lo trasforma in un report strutturato, senza richiedere alcuna configurazione oltre al percorso del file. HTTP access logs in Common Log Format hold valuable information (who visits what, when, with what outcome) but are awkward to read line by line. Traceweave takes any log file in this format and turns it into a structured report, with no configuration required beyond the file path.

Come funzionaHow it works

Il progetto è organizzato come una pipeline in cinque fasi: The project is organized as a five-stage pipeline:

  • FileReader legge il file grezzo riga per rigareads the raw file line by line
  • LogParser trasforma ogni riga in un oggettoturns each line into an HTTPRequest, aggregati in unaggregated into a ParsedLog
  • DataFrameBuilder converte i dati aggregati in un DataFrame pandasconverts the aggregated data into a pandas DataFrame
  • Analyzer calcola cinque riepiloghi: status, metodo, host, risorsa, distribuzione orariacomputes five summaries: status, method, host, resource, hourly distribution
  • ReportGenerator produce il report testuale e un grafico a barre del traffico orario con matplotlibproduces the text report and an hourly traffic bar chart with matplotlib

L'interfaccia a riga di comando è gestita con argparse: il file da analizzare è obbligatorio, mentre l'export del report e la generazione del grafico sono opzionali con valori predefiniti sensati. The command-line interface is handled with argparse: the file to analyze is required, while exporting the report and generating the chart are optional with sensible defaults.

Prossimo passoWhat's next

Il progetto è nato come singolo file (Traceweave.py) ed è ora in fase di refactoring verso una struttura modulare (main.py, models.py, parser.py, dataframe_builder.py, analyzer.py, report_generator.py), per avvicinarsi a come è organizzato un pacchetto Python reale. The project started as a single file (Traceweave.py) and is currently being refactored into a modular structure (main.py, models.py, parser.py, dataframe_builder.py, analyzer.py, report_generator.py), moving it closer to how a real Python package is organized.
